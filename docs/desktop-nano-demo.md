# Desktop Nano demo: preparation and evidence

Status: real Nano inference has not been verified. Do not label a mock or a cloud result as on-device AI.

## Device needed

Chrome on Android or iOS cannot run this web Nano path. Use a trusted desktop or laptop with Chrome 139+ (current Chrome recommended). Chrome's current requirements include at least 22 GB free profile-volume storage, an unmetered connection for the initial model download, and either more than 4 GB GPU VRAM or a CPU with at least 16 GB RAM and 4 cores. Supported desktop operating systems are listed in Chrome's documentation. A random low-spec cyber-cafe PC may not qualify. Do not spend money to obtain a machine.

## Steps Prit or a trusted helper must do

1. On the desktop, update Chrome at `chrome://settings/help`.
2. Open `chrome://flags/#prompt-api-for-gemini-nano-multimodal-input`, set Enabled, then relaunch Chrome.
3. Open https://formsathi.web.app/. Open Settings, ensure Demo mode is OFF, then use Check again.
4. If the Prompt API is missing or status is unavailable, stop. A cloud fallback is the honest alternative, not proof of Nano. Do not install an unknown extension or enter your Google password on a shared machine.
5. If downloadable, click Download Nano in Settings. Keep the tab open and wait for completion. Use an unmetered connection; download time depends on the machine and connection. Click Check again and confirm available.
6. Start screen recording. Show Settings with Demo mode OFF and Nano available. Close Settings, select a bundled fictional scholarship sample, and confirm the developer/region limits only if they apply to you.
7. Show the returned field list, then open the Router log. The decisive evidence is actualPath on-device, model Gemini Nano and 0 image bytes uploaded. If it says cloud, record that truthfully as fallback and do not claim Nano succeeded.
8. Fill only fictional answers. Record one interview turn and its real source badge. Never use real identity, bank, address or scholarship data in this contest recording.
9. Optional offline beat: after the model and app have loaded, disconnect the network and use a bundled sample. Only claim offline inference if a fresh successful call reports on-device while offline. A cached screen or local rules is not Nano.
10. Stop recording and send the file through the existing conversation. No Google sign-in is needed for the public app. If using a shared computer, clear this site's stored demo data afterward.
